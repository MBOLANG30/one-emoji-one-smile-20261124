A single-emoji entry for make.fun's "One Emoji, One Smile" bounty: exactly one warm emoji and nothing else — no words, no caption, no explanation. The entry is a gesture of warmth, a hug, chosen to read as kind and friendly at a glance to any stranger.

## Run it

```sh
node main.ts
```

This writes exactly one emoji (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
